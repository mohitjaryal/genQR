# 🧾 QR Code Generator (Python)

A simple yet powerful Python-based QR Code Generator that allows you to create custom QR codes for URLs, text, or any data — instantly and effortlessly.

---

## 🚀 Features

- ✅ Generate QR codes for any text or URL  
- 🖼️ Save the generated QR code as a `.png` file  
- 💡 Lightweight and beginner-friendly codebase  
- 🧩 Built using the popular `qrcode` and `Pillow` libraries  

---

## 🧰 Tech Stack

- **Language:** Python 3  
- **Libraries:**  
  - [`qrcode`](https://pypi.org/project/qrcode/)  
  - [`Pillow`](https://pypi.org/project/Pillow/)  

---

## 📦 Installation

Clone this repository and install the required dependencies:

```bash
git clone https://github.com/mohitjaryal/genQR.git
cd genQR
pip install qrcode[pil] or
pip install qrcode
pip install Pillow
```
